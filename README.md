## Projeto em destaque: Skilla, Marketplace de Freelancers (Angola)

**Skilla** é uma plataforma web freelance pensada para profissionalizar o mercado de serviços digitais em Angola, reduzindo fricção na contratação e aumentando confiança e segurança nos pagamentos.

### Problemas que a Skilla resolve
- Confiança: verificação + avaliações
- Organização: contratação centralizada (fim do “tudo no WhatsApp”)
- Segurança financeira: retenção/escrow simulado para garantir entrega

### Principais funcionalidades
**Para usuários**
- Perfis distintos (Cliente / Freelancer)
- Portfólio digital
- Busca e filtros por skills, categorias e avaliações

**Para clientes**
- Gestão de jobs (publicar/editar/encerrar)
- Gestão de propostas (valor/prazo)
- Escrow simulado

**Para freelancers**
- Envio de propostas (bidding por créditos)
- Dashboard de performance
- Boost de perfil

**Colaboração e segurança**
- Chat em tempo real (com arquivos)
- Avaliações bilaterais
- Notificações internas

### Stack do projeto
- Backend: Laravel (PHP)
- Frontend: Blade + Tailwind CSS
- Banco: MySQL
- Tempo real: Laravel Websockets
- Arquitetura: MVC
